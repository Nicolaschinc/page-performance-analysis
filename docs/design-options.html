🤖 AI 辅助性能优化工具 - 交互原型

既然核心诉求是“让你更好地使用 AI 辅助优化”，这里准备了三种不同的工作流/交互界面方案。

方案 A：左右分栏工作台

推荐

左侧展示 PageSpeed 的结构化数据（LCP/CLS 等和诊断列表），右侧为 AI 助手。点击左侧任意指标，右侧 AI 会立即针对该项提供代码级修复方案，支持多轮追问。

指标看板

CLS: 0.25 (需优化)
诊断：消除阻塞渲染的资源...

我分析了 JSON，发现首屏 Hero 图片加载过慢。建议在 head 中添加预加载：
<link rel="preload" as="image"...>
询问 AI 更多细节...

方案 B：报告流 + 内联 AI

类似 Notion 风格的沉浸式报告。工具将 JSON 解析为按优先级排序的问题流，每个问题下方都有一个“✨ 让 AI 修复”按钮，点击后在原地展开代码 diff。

淡化繁杂的指标数据，AI 后台消化完 Google API 的 JSON 后，直接输出一份“傻瓜式”的 Todo List。适合追求极简和执行力的开发者。
